# Техническое Задание: Todo-система «Цикл»

> Версия: Draft v1.0 | Дата: 2026-05-01

---

## 1. Основная концепция

Таск-менеджер, который сам следит за дисциплиной.  
Если задача не сделана в срок — она помечается как «неудача» и улетает в бэклог.  
Если сделана — сама уходит в архив.

---

## 2. Три уровня Канбана

Система разделена на три временных масштаба:

| Уровень | Период     | Назначение              |
|---------|------------|-------------------------|
| Week    | Неделя     | Оперативные задачи      |
| Month   | Месяц      | Среднесрочные цели      |
| Year    | Год        | Глобальные ориентиры    |

---

## 3. Жизненный цикл задачи

### Путь А — Выполнение

1. Пользователь ставит галочку «Сделано» → статус `done`
2. Задача висит в `done` (время ожидания настраивается, по умолчанию 2 часа)
3. По истечении времени — автоматически переходит в `archived`

### Путь Б — Просрочка

1. Наступает дедлайн (конец недели / месяца / года)
2. Задача не помечена как `done`
3. Система автоматически переводит задачу в `backlog` со статусом `failed`
4. Из бэклога можно: перепланировать → новый `todo`, или отправить в `archived` (провал)

### Статусы задачи

```
todo → done → archived
todo → backlog (failed)
backlog → todo (перепланирование)
backlog → archived (сдался)
```

---

## 4. Умное отображение (Сверху Вниз)

Задачи «старших» уровней всегда отображаются в «младших» видах.

### Вид «День»
- Первичные: задачи на сегодня (week-задачи с дедлайном сегодня)
- Контекст: активные задачи Недели
- Контекст: активные задачи Месяца
- Контекст: активные задачи Года

### Вид «Неделя»
- Первичные: week-задачи текущей недели
- Контекст: month-задачи + year-задачи

### Вид «Месяц»
- Первичные: month-задачи текущего месяца
- Контекст: year-задачи

### Вид «Год»
- Только year-задачи

### Маркировка уровня
У каждой задачи есть значок уровня (📅 Week / 🗓️ Month / 🎯 Year), чтобы всегда был виден масштаб цели.

---

## 5. Повторяющиеся задачи

Recurring-задачи автоматически создаются в начале каждого периода со статусом `todo`.

### Конфигурация
- **Week-задача**: каждую неделю, можно указать день недели (пн–вс)
- **Month-задача**: каждый месяц, можно указать день месяца (1–31)
- **Year-задача**: каждый год

---

## 6. Годовые задачи с месячным дедлайном

Year-задача может иметь дедлайн в конкретный месяц.  
По окончании месяца система проверяет статус и:
- `done` → архивируется как успех
- `todo` → переходит в `backlog` как провал

## 7. API (черновик)

| Метод  | Путь                 | Описание                        |
|--------|----------------------|---------------------------------|
| POST   | /api/auth/register   | Регистрация                     |
| POST   | /api/auth/login      | Вход                            |
| GET    | /api/tasks           | Список задач (фильтры)          |
| POST   | /api/tasks           | Создать задачу                  |
| PATCH  | /api/tasks/:id       | Обновить задачу / статус        |
| DELETE | /api/tasks/:id       | Удалить задачу                  |
